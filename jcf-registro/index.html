Privacidad y límites

Esta herramienta copia texto visible de una cédula; no confirma que el documento sea auténtico ni consulta a la Junta Central Electoral. No uses los datos para fines distintos a los autorizados. Protege el iPhone con código o Face ID y exporta los registros únicamente a un lugar institucional seguro.
